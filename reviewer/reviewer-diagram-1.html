In the participation model, 'runtime signals' refers only to application log output — not to error messages from CI tools or kubectl.
True

Runtime signals include any output from the running system: application logs, CI job output, kubectl error messages, scan results. The participation model treats all of these as signals Claude Code can correlate against code it produced.
