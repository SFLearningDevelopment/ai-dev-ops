Tier 1 — Single-file tasks
Contained, high-clarity examples. One file, one tool, one feedback loop.
Active

Each Tier 1 example is self-contained — a single file or config, a clear success criterion, and a feedback loop short enough to see the full arc in one session. These establish the prompting discipline and iteration habits that make Tier 2 and Tier 3 work.

Example 1 · Tier 1
Dockerfile for a Node.js API service
From a single-stage, root-running naive Dockerfile to a distroless, nonroot, layer-cache-optimised production image. Shows the full three-turn iteration loop.
